# Four mutually commuting tripotent matrices

`groups_4tripotent.zip` contains 20 text files `groups_4tripotent_blocksNN.txt` (218 MB unpacked), one per number of blocks NN, listing the 3 058 groups (characteristics) and all 415 916 closed systems with their solutions. `groups4_run.log` is the log of the run (279 192 024 solvable systems, 12 threads, 540 s enumeration + 47 s closure).
